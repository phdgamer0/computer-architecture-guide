Bölüm 4 — Register Transfer Language & Micro-operations
Yazaç Aktarım Dili ve Mikro İşlemler

4.1 Digital systems, micro-operations and RTL

A digital system sayısal sistem is a set of hardware modules modül connected by common data and control paths ortak veri ve denetim yolları. The modules are built from registers, decoders kod çözücü, arithmetic elements aritmetik eleman and control logic denetim mantığı.

A micro-operation mikro işlem is an elementary operation performed on the data stored in registers, completed in one clock pulse saat vuruşu. Examples are shift kaydırma, count sayma, clear silme and load yükleme.

We describe a digital computer by stating three things:

  1. the set of registers it contains and what they do içerdiği yazaç kümesi,
  2. the micro-operations performed on the data in those registers,
  3. the control functions denetim fonksiyonu that start the sequence of micro-operations.
Register Transfer Language (RTL) Yazaç Aktarım Dili RTL is a symbolic notation for describing the micro-operations that move data between registers. It is like a tiny programming language for hardware. Each RTL statement maps directly to wires and gates, so writing R2 ← R1 tells you exactly which circuit to build.

4.2 Register transfer and control functions

Copying information from one register to another is written with a left arrow:

R2 ← R1      // contents of R1 are copied into R2
  • R1 is the source kaynak. Its contents do not change kaynak yazaç içindeki bilgi değişmez.
  • R2 is the destination hedef. Its old contents are overwritten, so afterwards it holds the same value as the source.
  • In hardware, the n outputs of R1 are wired to the n inputs of R2, where n is the number of bits in the register yazaçtaki bit sayısı.

Usually we want the transfer to happen only under some condition. That condition is a Boolean variable called the control function denetim fonksiyonu, which is either 0 or 1:

P: R2 ← R1      // "if P = 1 then R2 ← R1"

The control circuit kontrol devresi generates P and connects it to R2's Load input yükleme girişi. All registers share the clock saat.

4.3 Bus and memory transfer · common bus built from multiplexers

A computer has many registers. Running a separate set of wires between every pair of registers would need far too many wires sayıları çoktur. Instead, all registers share one set of lines called the common bus ortak veri yolu: one bus line for each bit of the registers. Control signals pick which register drives the bus at any moment.

Recipe: bus with multiplexers (MUX)
  • Bit i of every register goes into MUX i. So MUX 0 collects all the bit-0s, MUX 1 all the bit-1s, and so on.
  • All MUXes share the same select lines seçim telleri S1S0, so they all pick the same register at once.
  • For k registers of n bits: you need n multiplexers, each of size k × 1, and log2k select lines.

Answer. Number of MUXes = number of bits = 16. Each MUX has one input per register, so 8 × 1. Select lines = log28 = 3. The bus is 16 bits wide.
Example 2 · transfer through the bus To do R1 ← C over the bus, we write it as two parts that happen in the same clock cycle: 
BUS ← C,   R1 ← BUS
Hardware: set S1S0 = 10 (selects C) and enable R1's Load input. At the next clock edge R1 = C.

4.4 Three-state bus buffers Üç durumlu veri yolu tamponları

A bus can also be built with three-state buffers instead of MUXes. A three-state gate has three possible output states:

  1. logic 0,
  2. logic 1,
  3. high-impedance yüksek direnç / yüksek empedans: the output is disconnected, like an open circuit açık devre. It has no logic meaning.

Binary incrementer İkili arttırıcı

The incrementer adds 1 to the number in a register. It can be built from half adders yarım toplayıcı (HA): one input of the first HA is fixed at 1, and each carry feeds the next HA. (In a real register, counting is usually done with a binary counter ikili sayıcı: each clock pulse with the count input active adds 1.)

4.8 Shift micro-operations Kaydırma mikro işlemleri

Shifts are used for serial transfer of data verilerin seri olarak aktarılması. A register's contents can be shifted left sola or right sağa. When the bits move, the bit at one end falls out, and the empty position at the other end is filled from the serial input seri giriş. The three kinds differ only in what that serial input is.

TypeRTLSerial input gets…
Logical mantıksal kaydırmaR ← shl R   R ← shr Ralways 0
Circular dairesel kaydırmaR ← cil R   R ← cir Rthe bit that just fell out at the other end. Nothing is lost bilgi kaybı olmadan.
Arithmetic aritmetik kaydırmaR ← ashl R   R ← ashr Rshl: 0 at the right. shr: the sign bit is kept işaret biti olduğu yerde kalır

Arithmetic shift in detail Aritmetik kaydırma

  • Arithmetic shifts treat the register as a signed number işaretli sayı in 2's complement. Sign bit = 0 means positive, sign bit = 1 means negative işaret biti 0 → pozitif, 1 → negatif.
  • Rn−1 is the leftmost bit and holds the sign. Rn−2 is the most significant value bit (MSB), and R0 is the least significant bit (LSB) en anlamsız bit.
  • ashl multiplies by 2 işaretli sayı × 2. A 0 enters R0, every bit moves left, Rn−2 replaces Rn−1, and the old Rn−1 is lost.
  • ashr divides by 2 işaretli sayı / 2. The sign bit is not touched, the other bits move right, and R0 is lost.
  • Overflow taşma: after ashl, if the value of Rn−1 has changed, the sign has flipped and the result is wrong. Detect it with Vs = Rn−1 ⊕ Rn−2, computed before the shift.
Example · overflow on ashl R = 0100 0000 (+64). ashl → 1000 0000, but that is −128, not +128. R7 changed from 0 to 1, so V = 0 ⊕ 1 = 1 and an overflow is flagged.
R = 1110 0000 (−32). ashl → 1100 0000 = −64 ✔ (R7 ⊕ R6 = 1 ⊕ 1 = 0, so no overflow).

4.9 Arithmetic Logic Shift Unit Aritmetik Mantık Kaydırma Birimi

Instead of giving each register its own adder and shifter, computer systems use one shared combinational unit, the ALU aritmetik mantık birimi. The contents of the chosen registers go into the ALU, the operation happens, and the result is loaded into a destination register, all within one clock pulse bir saat vuruşu süresinde.

Check against your notes The handwritten figure labels Ai−1 as shr and Ai+1 as shl. In Mano's textbook it is the other way round. For a right shift, bit i receives the bit from its left neighbour, Ai+1. For a left shift it receives Ai−1. The figure above follows the textbook.

Both transfers happen on the same clock edge, so R1 and R2 swap. The control function yT2 drives the Load input of both registers. R1's n outputs go to R2's inputs, and R2's n outputs go to R1's inputs.

Question 2 Implement if (P = 1) then (R1 ← R2) else if (Q = 1) then (R1 ← R3) using register transfer statements with control functions.
Show answer 
P:     R1 ← R2

The "else" matters: R1 ← R3 must happen only when P = 0, so the second control function is P'Q, not just Q. (The handwritten answer writes only "Q", which is incorrect when P = Q = 1.) Hardware: a 2×1 MUX in front of R1 picks R2 or R3 (select = P), and R1's Load = P + P'Q = P + Q.

Show answer(a) 32 MUXes of 16×1 each, with 4 select lines. (b) 16 × 32 = 512 three-state buffers and one 4×16 decoder, whose output k enables all 32 buffers of register k.

5.1 Instruction codes Buyruk kodu

  • A program is a sequence of instructions buyruk. Each instruction tells the computer which operation to perform.
  • An instruction is a binary code ikili kod that specifies a sequence of micro-operations.
  • Instructions are stored in memory together with the data buyruklar verilerle beraber bellekte bulunur. This is the stored-program idea saklanmış program yapısı.
  • The computer reads each instruction from memory into a control register (IR). The control unit then decodes it kodu çözer and executes the required micro-operations in order.
  • Every computer has its own instruction set buyruk kümesi.
  • The most basic part of an instruction is its operation code (opcode) işlem kodu – OPR: a group of bits that names the operation, such as add, subtract or shift. With n opcode bits you can have up to 2n distinct operations n bit → 2n işlem.

An instruction may also say where the operands are: in a register verilerin bulunduğu yazaç, at a memory address bellek adresleri, and where to put the result.

Stored program organization

Direct and indirect addressing Doğrudan ve Dolaylı Adresleme

The address part of an instruction can mean three different things:

  • Immediate anlık buyruk: the address field holds the operand itself, not an address.
  • Direct address doğrudan adres: the address field holds the address of the operand.
  • Indirect address dolaylı adres: the address field holds the address of a memory word that in turn holds the address of the operand.

In the Basic Computer, bit 15 is the I bit: I = 0 → direct, I = 1 → indirect. The opcode now has 3 bits (12–14).

Effective address etkin adres The effective address is the address where the operand actually is. In (a) it is 457. In (b) it is 1350. In both cases the instruction ends up using the word at the effective address.

5.3 Common bus system Ortak veri yolu sistemi

The basic computer has 8 registers + memory + control unit, all connected by one 16-bit common bus. The three select lines S2S1S0 choose which unit drives the bus. Each register has control inputs: LD (load yükle), INR (increment arttır), CLR (clear temizle).

Key facts about the bus (exam favourites)
  • Memory address comes only from AR belleğin adres girişine sadece AR bağlıdır.
  • AC can not be loaded directly from the bus. It loads from the adder & logic circuit. That is why LDA first reads memory into DR and then does AC ← DR.
  • INPR → AC goes through the adder & logic circuit. OUTR takes data from the bus but never drives it.
  • Two transfers can happen in the same clock cycle if one of them does not use the bus, e.g. DR ← AC, AC ← DR: AC goes onto the bus and into DR, while DR → AC goes through the adder & logic circuit.

5.5 Timing and control Zamanlama ve denetim

The control unit generates all the control signals. In the basic computer it is hardwired donanımsal: built from gates, decoders and a counter. (The other option, microprogrammed control, is Bölüm 7.)

  • SC (sequence counter sıra sayacı) is incremented at every clock pulse, so the timing signals come out in order: T0, T1, T2, T3, …
  • When an instruction finishes, the control sets SC ← 0. Then T0 is active again and the next instruction starts. SC = 0 → T0 sinyali durur, sıfırlanır.
  • Example: D3T4: SC ← 0 means "when the decoded instruction is D3 (STA) and we reach time T4, clear SC".

5.6 Instruction cycle Buyruk süreci

A program in memory is a sequence of instructions. Each instruction goes through a cycle made of sub-cycles alt süreçler:

  1. Fetch the instruction from memory buyruğun bellekten alınıp getirilmesi
  2. Decode the instruction buyruk kodunun çözülmesi
  3. If the instruction is indirect (I = 1), read the effective address from memory etkin adresin okunması
  4. Execute the instruction buyruğun icrası

Then go back to step 1. This loop continues until a HLT instruction is met HALT buyruğuna kadar sürer.

6.1 Machine language Makine dili

A computer system = hardware donanım (the physical parts) + software yazılım (the programs). A program is a list of machine instructions, given directly or indirectly, and stored in binary ikili yapı.

The basic computer has 25 instructions: 7 memory-reference, plus 18 register-reference and I/O (12 + 6). In this chapter:

  • m = the effective address efektif adreste belirtilen
  • M = the memory word (operand) found at m m adresindeki bellek kelimesi
  • For an indirect instruction, the I bit (bit 15) = 1 dolaylı adres buyruğu kip biti = 1

Program categories Program sınıfları

  1. Binary code ikili kod: the exact list of instructions and data, in 0s and 1s.
  2. Octal or hexadecimal code sekizlik veya onaltılık kod: the same binary code, written more compactly.
  3. Symbolic code sembolik kod: the user writes letters, digits and special characters for the operation (and for addresses). Each symbolic instruction can be translated into one binary instruction. Such a program is called an assembly language program birleştirici dil.
  4. High-level programming languages yüksek seviyeli programlama dilleri, e.g. Fortran, C. A compiler derleyici translates them into binary.
Assembler vs compiler An assembler birleştirici translates assembly (symbolic machine instructions), and each line becomes one machine word. A compiler translates a high-level language, and one statement often becomes many machine instructions. Assembly is a machine-level language makine seviyesinde dil.

A program loop program döngüsü is a sequence of instructions that runs many times. In Fortran it is written with DO:

6.6 Subroutines Alt programlar

Sometimes the same piece of code is needed in many places in a program. Instead of writing it out each time, we write it once and call it whenever it is needed. That piece is a subroutine alt program. When it finishes, it returns to the program that called it.

In the basic computer the link between the main program and the subroutine is the BSA instruction.

  • Going to a subroutine and coming back is called the linkage bağlantı. What BSA does is called a subroutine call alt program çağırma.
  • The last instruction of the subroutine, BUN SUB I, is the return alt programdan geri dönüş.
  • Computers with many processor registers often keep the return address in a register, called an index register indis yazacı.

6.7 Input–output programming Giriş-Çıkışın Programlanması

Input uses INP and SKI. Output uses OUT and SKO.

(a) Input one character bir karakter alma

CIF,    SKI         / check input flag
        BUN CIF     / flag = 0, branch to check again
        INP         / flag = 1, input character
        OUT         / print character (echo)
        STA CHR     / store character
        HLT
CHR,    —           / store character here
  • SKI checks the input flag to see whether a character is ready.
  • If FGI = 0, BUN goes back to check again (a busy-wait loop).
  • If FGI = 1, the next instruction is skipped. INP moves the character into AC(0–7) and clears the flag.
  • OUT echoes it to the printer, and STA saves it in memory.

(b) Print one character bir karakterin basılması

        LDA CHR     / load character into AC
COF,    SKO         / check output flag
        BUN COF     / flag = 0, branch to check again
        OUT         / flag = 1, output character
        HLT
CHR,    HEX 0057    / character is "W"
  • Load the character, already in memory, into AC.
  • Check the output flag. If it is 0, keep looping.
  • When the flag becomes 1, OUT moves the character from AC to the printer.

0x57 is the ASCII code of W.

Program interrupt Program kesmeleri

With the loops above, the computer spends almost all its time waiting for a device to raise its flag bilgisayarın çalışma zamanı, dış aletlerin bayrak kaldırmalarını beklemekle geçer. With interrupts, the I/O program does not have to keep checking the flags. When an external device raises its flag, the computer is told, and it can use the time in between for other work. This "notification" is called an interrupt kesme.

  • Interrupts are used when the computer runs more than one program.
  • The running program must be able to execute ION when it wants interrupts. If interrupts are not to be used, it executes IOF.
  • An interrupt is raised when an I/O device sets its flag to 1. The computer finishes the instruction it is currently executing, and then the interrupt happens. The return address is saved at address 0, and the instruction at address 1 is executed. From address 1, the program branches to the interrupt service routine.
An interrupt service routine must kesme servis yordamı içinde:
  1. Save the contents of the processor registers (AC, E) işlemci yazaçlarının içeriklerinin saklanması
  2. Find which flag was raised hangi bayrağın kaldırıldığının bulunması
  3. Service the device whose flag was raised bayrağı kaldırılan aletin hizmet görmesi
  4. Restore the processor register contents işlemci yazaç içeriklerinin tekrar yerlerine yazılması
  5. Turn the interrupt facility back on (ION) kesme olayının tekrar açılması
  6. Return to the running program çalışan programa dönüş
  • The processor register contents must be the same before and after the interrupt. Otherwise the interrupted program would run incorrectly.
  • While one interrupt is being serviced, other (lower-priority) interrupts are disabled, because the interrupt cycle clears IEN.
  • Another interrupt can only be accepted after the current service has finished. Interrupts are turned back on (ION) just before the return address is loaded into PC.

Exam cheat sheet Özet

Bölüm 4 in 10 lines
  • P: R2 ← R1: transfer happens only when P = 1, at the clock edge.
  • Bus with MUX: n MUXes of size k×1 (k registers, n bits).
  • Three-state: C = 1 → Y = A, C = 0 → high-Z. A decoder enables exactly one buffer.
  • Read: DR ← M[AR]. Write: M[AR] ← R1.
  • Subtract: A + B' + 1.
  • Arithmetic circuit: D = A + Y + Cin, with Y = B, B', 0, 1…1.
  • Logic: 16 functions, of which 4 are built (AND, OR, XOR, NOT) + a MUX.
  • Shifts: logical (0 in), circular (wrap around), arithmetic (keep sign; V = Rn−1⊕Rn−2).
  • ALU select S3S2: 00 arith, 01 logic, 10 shr, 11 shl.
Bölüm 5 in 10 lines
  • Memory 4096×16. Format: I(15) | opcode(14–12) | address(11–0).
  • AR, PC = 12 bits. INPR, OUTR = 8 bits. DR, AC, IR, TR = 16 bits.
  • Bus codes: 1 AR · 2 PC · 3 DR · 4 AC · 5 IR · 6 TR · 7 Mem.
  • Fetch: T0 AR←PC · T1 IR←M[AR], PC←PC+1 · T2 decode, AR←IR(0–11), I←IR(15)
  • T3: D7'I → AR←M[AR] · D7I' → reg · D7I → I/O.
  • r = D7I'T3, p = D7IT3, Bi = IR(i).
  • MRI start at T4. LDA, ADD and AND go via DR. ISZ needs T6.
  • BSA: M[AR]←PC, AR←AR+1; PC←AR. Return: BUN X I.
  • Interrupt: RT0 AR←0, TR←PC · RT1 M[AR]←TR, PC←0 · RT2 PC←PC+1, IEN←0, R←0, SC←0
  • LD(AC) = D0T5+D1T5+D2T5+pB11+rB9+rB7+rB6 · INR = rB5 · CLR = rB11.
Bölüm 6 in 10 lines
  • 25 instructions: 7 MRI + 12 register + 6 I/O.
  • Fields: Label, Instruction, Comment. Label ≤ 3 chars, starts with a letter, ends with ",".
  • Pseudo: ORG N (hex), END, DEC N, HEX N.
  • Assembler: pass 1 builds the address-symbol table with LC. Pass 2 translates using 4 tables.
  • Loop = pointer (ADD PTR I, ISZ PTR) + counter (−N, ISZ CTR).
  • Subtract: LDA B, CMA, INC, ADD A. OR: CMA … AND … CMA.
  • Logical shift: CLE + CIR/CIL. Arithmetic shift right: CLE, SPA, CME, CIR.
  • Multiply: shift Y right into E. If E = 1 then P += X. Shift X left. Repeat 8 times.
  • Subroutine: BSA SUB … SUB, HEX 0 … BUN SUB I. Parameters after BSA, read with LDA SUB I, skip with ISZ SUB.
  • Input: SKI/BUN/INP. Output: SKO/BUN/OUT. ISR: save, find flag, serve, restore, ION, return.
Common mistakes
  • Writing "AC ← M[AR]" as a single step. It must go through DR.
  • Forgetting SC ← 0 at the end of every instruction.
  • Forgetting that PC is already +1 after fetch (this matters for BSA and skips).
  • Using Q instead of P'Q in an else-if.
  • Thinking direct instructions skip T3. They don't: T3 simply does nothing.
  • Mixing up + (add) and ∨ (OR) in RTL.
  • DEC −N must be stored in 2's complement (e.g. −23 = FFE9).

  13. Why does an assembler need two passes?

    Show answerA symbolic address can be used before it is defined (a forward reference, e.g. LDA SUB before SUB, DEC -23). Pass 1 finds the address of every label and stores it in the address-symbol table. Pass 2 can then translate every instruction.
